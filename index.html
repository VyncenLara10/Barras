PREGUNTAS FRECUENTES

Todo claro,
antes de imprimir.

¿Funciona con Steren COM-597?

Los formatos Code 128 y QR son compatibles con lectores 1D/2D que admiten estas simbologías. La lectura física depende de la configuración específica de tu equipo, la impresión y la distancia.

¿La página guarda mi inventario?

El generador no guarda productos; la página de Inventario es opcional y sí guarda existencias e historial localmente en este navegador. Descarga respaldos periódicos porque los datos no se sincronizan entre equipos. Las bibliotecas del generador se cargan desde terceros (CDN).

¿Qué diferencia hay entre Code 128, EAN-13 y QR?

Code 128 acepta identificadores internos alfanuméricos; EAN-13 es numérico y requiere una longitud y dígito de control válidos; QR admite más información y requiere lector 2D. Para identificación comercial oficial, necesitas códigos GS1 debidamente asignados.

¿Cómo imprimir para que el lector pueda escanear?

Selecciona tamaño real o escala al 100%, utiliza impresión nítida y prueba con unas pocas etiquetas antes de generar un lote grande. Si el código es demasiado largo, cambia a etiquetas grandes.
